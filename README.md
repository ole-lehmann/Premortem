## 🛠️ Installation & Usage

1. **Add the skill:** Place `pre-mortem.md` into your agent's skills/prompts directory.
2. **Present a plan:** Share any roadmap, product spec, business strategy, or major decision.
3. **Trigger:** Run the command:
   ```text
   premortem this
   ```

---

## 📋 Output Breakdown

Every execution returns a structured diagnostic report covering:
* **Most Likely Failure:** The mundane, high-probability friction that stalls momentum.
* **Most Dangerous Failure:** The catastrophic blind spot that kills the initiative outright.
* **Biggest Hidden Assumption:** The core unproven bet you are making.
* **Revised Plan:** An updated, battle-tested version of your original move.
